# Events

Версионированные DTO событий, публикуемых через RabbitMQ (см. раздел 4 "Контракты событий RabbitMQ" в [spec.md](../../../spec.md)).

Правила:
- Один файл — одно событие, имя файла совпадает с именем события (например, `OrderCreated.cs`).
- Только данные (record/DTO), без бизнес-логики и зависимостей на конкретные сервисы.
- При breaking change — новая версия типа/неймспейса (`V2`), не правится опубликованный контракт задним числом.
