# document-service

Генерация документов по грузу: транспортная накладная, акт приёма-передачи, акт осмотра при
повреждении, QR/штрихкод трек-номера. См. раздел [3.1 spec.md](../../spec.md#31-document-service--генерация-документов).

Реализуется в рамках Фазы 8 (см. чек-лист в spec.md).

Пять слоёв по общему образцу монорепозитория: `DocumentService.Domain` / `.Application` /
`.Persistence` / `.Infrastructure` / `DocumentService` (API-хост). БД и пользователь Postgres —
`documentservice`, порт для будущей записи в `docker-compose.yml` зарезервирован **8089**.

Сервис одновременно потребитель и издатель событий: подписывается на `CargoAccepted` и
`CargoDelivered`, публикует `DocumentGenerated`, — поэтому у него будут и consumer с inbox, и
транзакционный outbox (как у ai-inspection-service). Сами PDF хранятся в file-storage-service,
у себя сервис держит только метаданные документа и идентификатор файла.

## Генерация PDF

Вёрстка — на **QuestPDF**, за интерфейсом `IDocumentRenderer` (Application): вёрстка это внешняя
подробность, и сценарии «кто и по какому событию печатает документ» от неё не зависят.
Библиотека используется по **Community-лицензии** — бесплатной для открытых проектов и
организаций с выручкой до $1 млн; лицензия объявляется явно в коде (`Settings.License`). При
выходе за эти рамки её меняют на коммерческую либо заменяют саму библиотеку — изоляция за
интерфейсом сделана в том числе ради этого.

**Шрифт вшит в сборку** (PT Sans, SIL OFL — файлы и текст лицензии лежат в
`DocumentService.Infrastructure/Fonts/`). В образе `dotnet/aspnet` системных шрифтов нет вовсе,
и документ с кириллицей вышел бы из контейнера набором пустых прямоугольников — молча, без
ошибок в логе. Поэтому же выключено использование шрифтов окружения
(`Settings.UseEnvironmentFonts = false`) и включена проверка глифов
(`CheckIfAllTextGlyphsAreAvailable`): отсутствующий символ обязан ломать генерацию, а не
печататься квадратом.

Три бланка (накладная, акт приёма-передачи, акт осмотра при повреждении) собираются из общего
каркаса — шапка перевозчика, заголовок с трек-номером и датой, таблица «поле — значение»,
подписи, нумерация страниц: различаются они набором строк, а не оформлением.

## Команды

```
dotnet build DocumentService.slnx
dotnet run --project DocumentService
```

Миграции (из `DocumentService.Persistence/`):

```
dotnet ef migrations add <Name>
dotnet ef database update
```
